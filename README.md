# Quwwat

Pakistan-friendly fitness planner — enter height, weight, and goals to get a desi meal plan and training routine.

## Features

- **Goals from your numbers** — height, current weight, goal weight, age, activity
- **Calorie & macro targets** — Mifflin-St Jeor BMR + TDEE with deficit/surplus
- **7-day Pakistani diet plan** — tikka, daal, roti, dahi, chana, and more (halal)
- **Exercise plans** — fat loss, muscle gain, or maintain · gym or home
- **Grocery staples** — bazaar-friendly weekly list
- **Saved locally** — your profile persists in the browser

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Stack

React + TypeScript + Vite + Framer Motion
