# Jettribe Redesign

Modern storefront recreation of [jettribe.com](https://www.jettribe.com) with:

- Homepage layout inspired by the attached minimal e-commerce mockup (hero, collections, bestsellers, promo sidebar)
- Product detail page matching the second mockup (gallery, size pills, accordions, reviews, related)
- Cursor wipe animation when switching product color variants

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Product demo: [/product/rs-25p-fade-impact-vest](http://localhost:3000/product/rs-25p-fade-impact-vest)

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4
- Product imagery from the live Jettribe BigCommerce CDN
